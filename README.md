# South Goa Apartment Search Tool

A Python tool to search for newly constructed or under-construction 3 BHK apartments in South Goa.

## Target Areas
- Colva
- Betalbatim
- Utorda
- Seraulim
- Benaulim
- Varca

## Features
- Searches multiple property portals (99acres, MagicBricks, Housing.com)
- Filters for new/under-construction properties
- Saves results to JSON format
- Provides area-wise breakdown

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python apartment_search.py
```

## Output

The tool generates `apartment_results.json` with:
- Search criteria
- Total number of listings
- Detailed results with area, price, location, etc.

## Important Notes

⚠️ **Legal & Ethical Considerations:**
- This tool is a template/framework for apartment searching
- Actual web scraping requires:
  - Respecting robots.txt
  - Following terms of service
  - Rate limiting requests
  - Handling dynamic content (may need Selenium/Playwright)

💡 **Alternative Approaches:**
1. Use official APIs from property portals (if available)
2. Manual search on property websites
3. Contact local real estate agents
4. Visit builder websites directly
5. Check RERA (Real Estate Regulatory Authority) website for registered projects

## Tips for Apartment Hunting

1. **Verify RERA Registration**: Check if the project is RERA registered
2. **Builder Reputation**: Research the builder's previous projects
3. **Location**: Visit the area personally to check connectivity and amenities
4. **Legal Documents**: Verify all legal documents before booking
5. **Payment Plan**: Understand the payment schedule
6. **Amenities**: Check what amenities are included
7. **Possession Date**: Confirm realistic possession dates for under-construction projects
