# South Goa 3 BHK Apartment Search Guide

## Quick Search Strategy

### 1. Property Portal Searches

#### 99acres.com
1. Go to https://www.99acres.com
2. Select: Buy → Apartment → Goa → South Goa
3. Filter by:
   - BHK: 3 BHK
   - Status: Under Construction / New Projects
   - Location: Colva, Betalbatim, Utorda, Seraulim, Benaulim, Varca
   - Price Range: Set your budget
4. Sort by: Newest First

#### MagicBricks
1. Go to https://www.magicbricks.com
2. Select: Buy → Apartment → Goa
3. Apply filters:
   - Bedrooms: 3
   - Property Type: Apartment
   - Status: Under Construction / Ready to Move
   - Location: Your preferred areas
4. Check "New Projects" filter

#### Housing.com
1. Go to https://www.housing.com
2. Navigate to Buy → Apartments → Goa
3. Filter by:
   - 3 BHK
   - New Launches / Under Construction
   - Specific areas

## Important Checklist

### Before Booking
- [ ] RERA registration verified
- [ ] Builder reputation checked
- [ ] Site visit completed
- [ ] Legal documents reviewed
- [ ] Payment plan understood
- [ ] Amenities confirmed
- [ ] Possession timeline realistic
- [ ] Location connectivity verified
- [ ] Nearby facilities checked (schools, hospitals, markets)
- [ ] Resale value potential assessed

### Documents to Verify
- RERA registration certificate
- Building plan approval
- Environmental clearance
- Land title documents
- Builder's track record
- Previous project reviews
